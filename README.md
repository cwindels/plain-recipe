# Plain Recipe

Bookmarklet that extracts the ingredients, steps and notes from recipe webpages. Runs entirely in your browser. Generated by Claude.

**Install:** https://cwindels.github.io/plain-recipe/

Drag the green button to your bookmarks bar, then click it on any recipe page to see a clean card with the ingredients, steps and notes. It reads the recipe data most food sites already include for search engines, plus the recipe card from common plugins (WP Recipe Maker, Tasty Recipes, Mediavine Create), so optional ingredient groups and card notes are kept.
